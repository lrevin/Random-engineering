# 구글 AdMob 설정

## 현재 상태 (2026-11-14 만듦, 팀장 계정)

| | Android | iOS |
|---|---|---|
| 앱 ID | `ca-app-pub-2812024386507663~6466504174` | `ca-app-pub-2812024386507663~8821204770` |
| 보상형 '톱니바퀴 보상' (10 톱니바퀴) | `ca-app-pub-2812024386507663/1651172098` | `ca-app-pub-2812024386507663/3760274779` |

- 앱 ID는 `app.json`, 광고 단위는 `src/lib/ads.ts`에 이미 넣었어요. 이 값들은 비밀값이 아니라 APK 안에 들어가는 값이에요.
- **남은 일:**
  - **결제 프로필 작성:** 계정 주인이 AdMob > 지급 화면에서 이름과 주소를 직접 넣어야 해요. 이걸 하기 전에는 앱 검토가 보류돼요.
  - **스토어 연결:** 출시 후에 AdMob 앱을 스토어 앱과 연결하고 app-ads.txt를 올려요. 그 전까지는 "광고 게재 제한" 상태예요.


앱에는 이미 **보상형 광고**가 들어가 있습니다.
- 위치: 상점과 배틀 탭의 "광고 보고 톱니바퀴 받기"
- 보상: 1회에 10개, 하루 3번까지
- ID: 실제 ID가 없으면 구글 공개 시험용 ID를 씁니다.

실제 광고를 붙이려면 아래 순서대로 AdMob 계정 작업을 하고, 받은 ID를 환경변수에 넣으면 됩니다. 코드를 고칠 필요는 없습니다.

## 1. 계정 만들기 (팀장 구글 계정)

1. <https://admob.google.com> 에서 시작합니다. 나라는 대한민국, 시간대는 서울로 합니다.
2. **결제 > 결제 정보**에서 수익을 받을 사람(이름, 주소)을 등록합니다.
   - 수익이 쌓이면 주소 확인용 PIN 우편이 옵니다.
   - 실제 지급 계좌는 수익이 기준액을 넘은 뒤 등록합니다.

## 2. 앱 등록

**앱 > 앱 추가**를 누릅니다.
- **Android**: 아직 스토어에 올리지 않았으면 "아니요"를 고릅니다. 앱 이름은 뽑공으로 합니다.
- **iOS**: 같은 방법으로 하나 더 등록합니다.

등록하면 **앱 ID**(`ca-app-pub-…~…`)가 나옵니다.

## 3. 광고 단위 만들기

각 앱에서 **광고 단위 > 보상형**을 고릅니다.
- 이름: 톱니바퀴 보상
- 보상: 10, 톱니바퀴 (앱이 주는 양은 코드가 정합니다. 이 값은 표시용입니다)

만들면 **광고 단위 ID**(`ca-app-pub-…/…`)가 나옵니다.

## 4. 앱에 넣기 (`app/.env.local`, 팀원 APK는 EAS 환경변수)

```
ADMOB_ANDROID_APP_ID=ca-app-pub-…~…          # 2번 앱 ID (빌드 때 들어감 → 다시 빌드 필요)
ADMOB_IOS_APP_ID=ca-app-pub-…~…
EXPO_PUBLIC_ADMOB_REWARDED_ANDROID=ca-app-pub-…/…   # 3번 광고 단위 ID
EXPO_PUBLIC_ADMOB_REWARDED_IOS=ca-app-pub-…/…
```

- 개발 빌드(`__DEV__`)에서는 실제 ID를 넣어도 **항상 시험용 광고**가 나옵니다. 자기 광고를 눌러 정지당하는 일을 막기 위해서입니다.
- 실제 광고는 출시용(release) 빌드에서만 나옵니다.
- 출시용 빌드로 시험할 때는 AdMob **설정 > 기기 테스트**에 자기 휴대폰을 등록합니다. 자기 광고를 누르면 계정이 정지될 수 있습니다.

## 5. 스토어에 올린 뒤

- AdMob에서 앱을 스토어 앱과 연결합니다.
- `app-ads.txt`를 개발자 웹사이트에 올립니다. 스토어 등록 정보의 웹사이트 주소에 둬야 합니다.
