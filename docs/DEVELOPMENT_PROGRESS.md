## 1. 최신 develop의 변경점

2026-11-14 로컬을 원격 develop의 `478a4b4`에 맞췄다. 이전 개인 작업 커밋 `561cf9a`가 develop에 이미 포함돼 fast-forward로 반영했으며 Git 충돌은 없었다. 로컬 미커밋 변경은 패치·stash로 보존 후 복원했다. 카카오 테스트 대체 구현은 develop에도 있어 중복만 제거했다. 현재 기준 브랜치는 로컬 develop이며 이후 작업은 여기서 새 feature 브랜치를 만든다.

## 2. 우리 서버 코드와 통합하면서 수정한 점

| 대상 | 통합 결과 |
|---|---|
| `app-state.tsx` | MySQL 인증·계정 분리·기록 동기화·서버 재화 유지. 스피드 XP를 서버에서 읽어 회원 총 XP에 합산 |
| `quiz.ts` | 내장 기본 문제·자체 문제 API·캐시 유지. 스피드 연습 문제 생성 함수를 함께 반영 |
| 홈·설정·기록·결과 | 최신 화면·분야 랭크를 반영하면서 답안 저장·서버 XP·메모 충돌·목록 갱신을 보존 |
| 스피드 회원 풀이 | 기기 점수로 XP를 올리던 방식을 서버 문제 발급·답안 채점·시간/지급 한도 검사로 변경 |
| 게스트·오프라인 스피드 | XP 없는 연습으로 제공. 연습 최고 기록·플레이 수는 기기에 저장 |
| 개발용 시험 기록 | 개발 빌드의 게스트 전용. `devOnly` 표시 후 로그인 시 회원 동기화·XP에서 제외 |
| DB·인증 | V4 스피드, V5 배틀·대기열 추가. 공통 풀이·XP 원장을 재사용하며 Supabase 코드·의존성은 재도입하지 않음 |

회원 보상·권한은 서버가 확정하고 기기는 캐시·진행·전송 대기를 저장한다. 서버 미연결 기능은 준비 상태나 보상 없는 연습으로 표시한다.

스피드는 서버 기준 60초·최대 100문제, 정답당 3 XP·한국 시각 하루 최대 150 XP다. 보상 날짜는 시작 날짜로 고정하고 재전송·동시 완료로 중복 지급하지 않는다. 회원 레벨에만 합산하며 일반 7문항 기록·분야 랭크·일반 학습 퀘스트와 분리한다. 오프라인 연습 결과를 나중에 XP로 지급하지 않는다.
