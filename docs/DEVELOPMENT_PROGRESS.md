스피드는 서버 기준 60초·최대 100문제, 정답당 3 XP·한국 시각 하루 최대 150 XP다. 보상 날짜는 시작 날짜로 고정하고 재전송·동시 완료로 중복 지급하지 않는다. 회원 레벨에만 합산하며 일반 7문항 기록·분야 랭크·일반 학습 퀘스트와 분리한다. 오프라인 연습 결과를 나중에 XP로 지급하지 않는다.

## 5. 마지막 검증·반영 상태

- 검증일: 2026-11-14. 로컬 MySQL 8.0.46·Flyway 13.12.1 임시 DB에서 자동 통합 검사 **124개 통과**, 실패·건너뜀 0개.
- DB: 로컬 개발 DB를 백업 후 V2→V5 적용·검증. RDS와 V1~V5 이력·체크섬 및 업무 테이블 31개(이력 포함 32개) 일치. 이번 정리에서 RDS 추가 변경 없음.
- 앱 검사: 27개 통과. 배틀 실적 제외 규칙·대기 요청 UUID·스킵 동의/취소·한국 날짜 경계 포함. 통합 검사와 중복되므로 합산하지 않음.
- EC2 검사: 기본 API·마이그레이션 회귀 9개 및 AI 모의 검사 통과. 실제 AI 생성·상시 AI 서비스 연결은 보류 유지.
- 환경 정리: 최신 검사 6개·AI 공용 데이터 경로·앱 소스 반영, 이전 Supabase 함수/스키마/클라이언트·후보 앱 제거. API·앱 소스·검사·패키지 명세 145개 일치(줄바꿈 정규화). 문서·Git 이력·환경 설정·설치/빌드 결과물은 비교 제외.
- 운영 API: 재시작 후 active/enabled·Restart=always 확인. 공개 HTTPS의 상태·목록·문제 200, 삭제한 다운로드 경로 404, 미인증 인증 조회 401 확인. 기존 두 계정의 인증·친구·매칭·정산·기록 검사도 완료.
- 배포 방식: GitHub 커밋·push 없이 SCP로 파일/압축 묶음을 전송하고 SSH로 백업·반영·검사·재시작. 원격 develop 병합과 구분. 운영 반영 후 현재 변경을 작업 브랜치의 공유 커밋·push 대상으로 정리함.
- 배틀·학습 스킵: 서버 매칭·진행·정산 및 양쪽 동의/취소·즉시 퀴즈 전환을 운영 API·APK에 반영. 휴대폰·에뮬레이터 간 친구·배틀 동작은 사용자 확인.
- 요청·DB 안정화: 중복 로그인 확인 요청 제거·회원별 한도 분리·중복 갱신 방지, 공용 조회 풀 최대 10개·유휴 종료 후 연결 복구 적용. 모든 DB 연결을 합친 상한 10개라는 의미는 아님.
- 날짜 통일: Asia/Seoul 기준 출석·일/주/월 기간·보상 키·초기화 시간 반영. 화면 안내는 추가하지 않음.
- 화면·APK: 콘텐츠 스크롤 및 하단 탭 잘림·중복 여백 수정. 타입·린트 통과, release 재빌드·전용 서명 검증·에뮬레이터 업데이트 확인. APK는 app/android/app/build/outputs/apk/release/app-release.apk, 약 123MiB.
