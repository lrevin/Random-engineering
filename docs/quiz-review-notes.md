# 퀴즈 검토 메모

작성 중에 "검토가 필요하다"고 표시된 문제 목록입니다. 해당 분야를 아는 팀원이 확인해 주세요.

## sec-4, ds-2
- sec-61: 디지털 포렌식 원칙(재현·정당성 등) 명칭은 교재마다 표현이 다를 수 있음
- sec-65: ISO/IEC 27001 Annex A·27002 관련 문항은 판(edition)에 따라 달라지지 않게 일반적으로 표현함
- ds-22: 랭크에 의한 합치기 + 경로 압축 → 연산당 상각 O(α(n))
- ds-26: 해시 함수가 너무 많으면 거짓 양성률이 오히려 올라간다는 문항 (맞지만 미묘함)

## sec-1
- sec-07: OWASP Top 10 항목명("취약하고 오래된 구성 요소")은 2021년판 기준. 새 판에서 이름이 바뀔 수 있음
- sec-13 OX: IV 설명에 TLS 1.0 BEAST 공격 사례를 듦 (정답은 맞지만 예시가 구체적)
- sec-17: "SHA-2를 FIPS 표준으로 발표한 기관" (NIST) — 기관명 암기형
- 계산 문제 직접 검산함: RSA d=27, DH 공유키=18, ECC 곡선 값=36

## sec-3
- sec-49: 사회공학 "콰이드 프로 쿼(quid pro quo)" 용어가 덜 알려짐
- sec-41: "ESP의 IP 프로토콜 번호는?" (50) — 암기형
- sec-50: 워너크라이/SMB 사례 문항
- sec-47: FIN 스캔 닫힌 포트 → RST (RFC를 따르는 시스템 기준이라고 문제에 명시)
- 정답 위치를 스크립트로 섞어서 CVSS 등급 보기 등은 자연스러운 순서가 아닐 수 있음

- ds-12 OX: 삽입 후 한 번의 회전(단일/이중)으로 균형 복구 (참)
- ds-14: B-트리 최소 자식 수 ⌈m/2⌉ — 교재마다 차수 정의가 다를 수 있음
- ds-15: B+ 트리 리프 분할 시 키를 부모로 "복사" (교재 관례)
- ds-18 OX: 트라이를 IP 라우팅에 사용 (참)
