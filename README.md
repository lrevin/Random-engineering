# Random Engineering — 뽑공 (뽑는 공학 공부)

> 랜덤 공학 주제 하나, **15분 공부하고 퀴즈 10문제**

경동대학교 컴퓨터공학과 2026학년도 2학기 캡스톤 디자인 프로젝트. 공학 11개 분야 · **854개 개념** 중 하나를 랜덤으로 뽑아 위키백과·공식 문서로 15분 동안 스스로 공부하고, **퀴즈 10문제**로 확인하는 모바일 학습 앱이다.
듀오링고처럼 매일 알림, 연속 학습 일수(스트릭), **브론즈 → 실버 → 골드 → 플래티넘 → 다이아 → 엔지니어** 랭크로 꾸준한 학습 습관을 만든다.

| 폴더 | 내용 |
|---|---|
| [`app/`](app) | 모바일 앱 — React Native 0.86 · Expo SDK 57 · TypeScript (iOS·안드로이드 공용) |
| [`api/`](api) | 백엔드 — Supabase (PostgreSQL · Auth · RLS) + AI 퀴즈 서버 함수 (Deno · Claude API) |
| [`api/API_RULES.md`](api/API_RULES.md) | **API 규칙** — 엔드포인트 목록, 이름·인증·오류 형식, DB 변경 방법 |
| [`docs/`](docs) | 졸업작품 계획서(`docs/plan`), 로고·그림(`docs/images`), 퀴즈 작성 기준·검토 메모 |
| [`scripts/`](scripts) | 주제·퀴즈 데이터 생성·검사 도구 (Python) |

## 학습 흐름
```
회원가입 → 온보딩(공학 분야 여러 개 선택 → 세부 분야 → 시작 난이도 → 알림)
   → 주제 뽑기 → 한국어 위키백과 / 공식 문서 보며 15분 공부 → 퀴즈 10문제 → RP 획득 · 랭크 상승
```

## 주요 기능
- **분야 고르기**: 가입 후 온보딩에서 공학 분야를 카드로 여러 개 선택, 세부 분야와 시작 난이도(Lv.1~3 / 골고루) 설정
- **주제 뽑기**: 관심 분야·난이도 필터, 슬롯머신 애니메이션, 이미 공부한 주제 제외
- **공부 자료 바로가기**: 각 주제의 **실제 한국어 위키백과 문서**(718개)와, 표준이 있는 주제는 **공식 문서**(RFC·NIST·W3C·WHATWG·ISO·IEEE 등 60개) 버튼
- **15분 공부**: 원형 타이머, 자동 저장 메모, 앱을 껐다 켜도 이어 하기, 끝나는 순간 알림
- **퀴즈 10문제**: 4지선다 7 + OX 3, 문제마다 정답·해설 바로 표시, 오답 노트, 퀴즈만 다시 풀기
  - 문제 출처: 앱 내장 문제 은행 → (서버 연결 시) AI가 만든 문제 → 연습 문제
- **랭크**
  - 사용자 랭크: 퀴즈로 얻은 RP 누적 (실버 300 · 골드 900 · 플래티넘 2,000 · 다이아 4,000 · 엔지니어 7,000)
  - 주제별 숙련 랭크: 그 주제에서 맞힌 문제 누적 (실버 15 · 골드 30 · 플래티넘 45 · 다이아 60 · 엔지니어 75 + 만점 1회)
  - 주제마다 다른 RP: 정답 1개당 Lv.1 4 · Lv.2 6 · Lv.3 9 RP, 만점 +20%, 첫 클리어 +Lv×10, 3일 연속 +10%, 복습 ×0.7 / ×0.5
- **기록·통계**: 연속 학습 일수 🔥, 최근 7일, 분야별 횟수, 다시 볼 주제(6점 이하)
- **매일 알림**: 그날 공부했으면 건너뛰고, 연속 기록이 끊기기 전에 알려 주는 스마트 알림
- **회원 / 둘러보기**: 이메일 회원가입(카카오·Apple 예정) 또는 로그인 없이 사용, 가입 시 기록 이전, 앱 안에서 회원 탈퇴

## 개발 도구
- **GitHub Actions**: 올릴 때마다 앱 타입·코드 검사와 퀴즈 데이터 검사를 자동 실행 (Actions 탭)
- **브랜치(Git Flow)**: `main` 발표·배포용, `develop` 개발 통합, 기능은 `feature/기능이름`에서 만들어 develop으로 합친다

## 실행 방법
자세한 내용은 각 폴더의 안내를 본다.
- 앱: [`app/README.md`](app/README.md) — 실행 방법, 폴더 구조, 에뮬레이터
- 서버: [`api/API_RULES.md`](api/API_RULES.md) — API 목록, DB 만들기, 서버 함수 배포
- 퀴즈 문제 추가: [`docs/quiz-authoring.md`](docs/quiz-authoring.md)

```bash
cd app
npm install
npx expo start            # 휴대폰 Expo Go 앱으로 QR 코드 스캔
npx expo start --android  # 안드로이드 에뮬레이터
```
서버를 연결하지 않아도 **둘러보기 모드**와 내장 퀴즈로 동작한다.

## 데이터 도구 (저장소 루트에서 실행)

## 저장소에 없는 파일 (각자 준비)
보안 때문에 올리지 않는다. 팀장에게 따로 받는다.

| 파일·값 | 위치 | 용도 |
|---|---|---|
| `.env.local` | `app/` | Supabase 주소와 Publishable key (`app/.env.example` 참고) |
| `ANTHROPIC_API_KEY` | Supabase secrets | AI 퀴즈 생성 (코드·파일에 적지 않음) |
| Supabase service role 키 | Supabase 대시보드 | 서버 함수 전용, 앱·저장소에 절대 넣지 않음 |
